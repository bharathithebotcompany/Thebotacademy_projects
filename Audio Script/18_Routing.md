Adhukkudhaan Routing.

Routing-na incoming query-ah analyse panni correct data source or processing path-ku direct panradhu.

For example, "Explain our company leave policy" nu user kekkuranga. Idhu document-based question. Vector database suitable-ah irukkalaam.

"What are today's technology headlines?" nu kekkuranga. Latest information thevai. Web search suitable-ah irukkalaam.

Routing-la two useful approaches irukku.

Second, semantic routing. Question-oda meaning or intent base panni route select panradhu. Embeddings or a classifier use panni query endha category-ku belong aagudhu-nu identify pannalaam.

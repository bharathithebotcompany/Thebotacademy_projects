Adhai address panna RAPTOR use pannalaam.

RAPTOR stands for Recursive Abstractive Processing for Tree-Organized Retrieval.

Idhoda idea, documents-ah different levels of abstraction-la organise panradhu.

First, original document-ah smaller chunks-ah split pannuvom. Andha chunks-oda embeddings generate pannuvom. Similar content irukkura chunks-ah cluster pannuvom.

Cluster-na related content-ah oru group-ah organise panradhu.

Next, each cluster-ku summary generate pannuvom. Indha summaries-ahyum embeddings-ah represent pannuvom. Appuram summaries-ah higher-level groups-ah cluster panni, additional summaries create pannalaam.

Ippadi multiple levels create aagi tree structure maadhiri form aagum.

Bottom level-la original detailed chunks irukkum. Higher levels-la broader summaries irukkum.

Ippo specific detail question-na lower-level chunk retrieve pannalaam. Overall concept or cross-section question-na higher-level summary retrieve pannalaam.

Idhudhaan RAPTOR-oda main advantage. Detailed information and high-level context rendu levels-layum search panna support pannum.

Aana summary generate pannumbodhu original source-oda specific details miss aagalaam. So, summary mattum final evidence-ah use pannaama, necessary-aana original chunks-um retrieve pannanum.

RAPTOR long-document understanding-ku oru approach.

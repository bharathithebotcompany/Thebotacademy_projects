MMR-na relevance and diversity rendu balance panra retrieval technique.

Relevance-na user question-ku result evlo related-ah irukku-ngradhu.

Diversity-na already select panna results-oda compare pannumbodhu, new result evlo different useful information provide pannudhu-ngradhu.

Oru simple example. Neenga five research articles search panreenga. Five articles-um same paragraph and same explanation repeat pannina, adhu five different insights provide pannaadhu.

MMR, query-ku relevant-ah irukkura result-ah select pannum. Aana already select panna results-oda romba similar-ah irundha, different useful result-ku preference kudukkalaam.

Technical-ah, relevance score-ku oru weight kuduppom. Selected results-oda similarity-ku another weight kuduppom. Indha rendu factors balance panni next result select pannuvom.

Lambda-nu oru parameter use pannalaam. Lambda high-ah irundha relevance-ku adhiga importance. Lambda low-ah irundha diversity-ku adhiga importance.

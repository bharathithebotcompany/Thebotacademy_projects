Unsupervised Learning – Finding Patterns Without Correct Labels

Appo model enna learn pannum?

Indha learning approach dhaan Unsupervised Learning.

Reinforcement Learning – Learning Through Actions and Rewards

Ippo third approach-ku pogalaam.

Indha approach Supervised and Unsupervised Learning rendulaiyum irundhu konjam different-ah work aagum.

Idha understand panna oru simple game situation imagine pannunga.

Oru computer game-la oru character irukku.

Andha character forward, left and right move pannalaam.

Obstacle-la hit aanaa points lose aagalaam.

Ippo indha game play panra system starting-la correct path enna-nu theriyama different actions try pannum.

Oru action edukkumbodhu, adhoda result-ah observe pannum.

Indha learning approach dhaan Reinforcement Learning.

Reinforcement Learning-la sila important terms irukku.

First, Agent.

Agent-na environment-la actions perform panra learning system.

Namma game example-la game character or game play panra automated system agent-ah irukkalaam.

Next, Environment.

Environment-na agent interact panra surrounding world or situation.

Indha example-la game itself environment.

Next, Action.

Action-na agent edukkura move or decision.

Forward move panradhu, left move panradhu, right move panradhu ellame actions.

Next, Reward.

Reward-na agent edutha action-oda result eppadi irundhuchu-nu indicate panra feedback value.

Destination reach panninaa positive reward kidaikkalaam.

Obstacle-la hit aanaa negative reward or penalty kidaikkalaam.

Agent indha rewards-ah use panni future-la better actions select panna learn pannum.

So, Reinforcement Learning-la Agent, Environment, Action and Reward romba important concepts.

Indha approach game-playing systems mattum illaama, robotics and automated decision-making maadhiri areas-layum use aagalaam.

For example, oru robot oru environment-la move panni destination reach panna learn pannanum-na, different actions try panni, andha actions-oda results base panni improve aagalaam.

Aana real-world robotics-la sensors, planning and safety systems maadhiri additional technologies-um thevaippadalaam.

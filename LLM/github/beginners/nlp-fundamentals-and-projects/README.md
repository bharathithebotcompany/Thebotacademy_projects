This repository includes a series of NLP (Natural Language Processing) exercises and mini-projects built during my learning journey in Data Science.
It covers the entire foundation of NLP — from basic text cleaning and preprocessing to advanced topics like Word Embeddings and Machine Translation.

Each script or notebook focuses on a key concept, making this repo a great reference for beginners learning how to process and analyze textual data using Python and libraries like NLTK, spaCy, and scikit-learn.

# 🧠 NLP Basics and Projects

This repository contains a collection of Natural Language Processing (NLP) mini-projects and experiments.  
Each file demonstrates an important concept used in text preprocessing, vectorization, and deep learning for NLP.

## 📂 Folder Structure

| File / Folder | Description |
|----------------|-------------|
| **tokenization.py** | Demonstrates text tokenization using NLTK and spaCy. |
| **stem.py** | Implements stemming using Porter and Snowball stemmers. |
| **lemmatization.py** | Explains how to reduce words to their root form using lemmatization. |
| **TFIDF.py** | Shows TF-IDF vectorization for text features. |
| **BOW.py** | Demonstrates Bag of Words model. |
| **NLP_PART 1.ipynb** | A complete introduction to NLP with examples. |
| **NLP-Word Embedding, CBOW, SkipGram.ipynb** | Explains Word2Vec concepts and implementation. |
| **MULTIPLE LANGUAGE TRANSLATION/** | A small project for text translation using APIs or pretrained models. |
| **CHATBOT PROJECT/** | A rule-based / ML-based chatbot implementation. |
| **customer review dataset/** | Dataset used for text classification / sentiment analysis. |

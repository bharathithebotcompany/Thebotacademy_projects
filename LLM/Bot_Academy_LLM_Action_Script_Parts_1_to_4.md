# GLOBAL PRODUCTION INSTRUCTIONS

These instructions apply to every scene in this action script.

### 1. Voice and visual synchronization

- Use the supplied ElevenLabs voice recording as the master timeline.
- Do not rewrite, shorten, rearrange or paraphrase the spoken narration.
- Every visual must appear when its corresponding concept is spoken.
- Do not show a future concept before the narration introduces it.
- Do not leave a visual on screen after the narration has moved to another concept.
- Use the scene timestamps as approximate editing references. Final cuts must follow the actual voice recording.
- Keep the screen readable. Do not display multiple unrelated concepts simultaneously.

### 2. Visual design

Use a consistent visual identity throughout the four parts:

- Modern educational technology aesthetic.
- Dark navy or charcoal background for technical explanations.
- White text with restrained blue and cyan highlights.
- Clean typography, simple diagrams and smooth transitions.
- Use realistic computer screens when showing coding.
- Use simple 2D or 3D animations when explaining abstract concepts.
- Keep important labels large enough to read.
- Avoid decorative animations that do not communicate anything.
- Avoid unnecessary futuristic robots, floating holograms and random AI imagery.

### 3. Code demonstration rules

- Show code in a realistic code editor or terminal interface.
- Reveal code progressively, in the order it is discussed.
- Highlight the exact line or method currently being narrated.
- Do not display the complete code before the narration reaches it.
- When the voice explains a symbol, highlight that symbol.
- Show the actual execution process and actual output.
- Never invent token IDs, token strings, probabilities or other runtime values.
- If output depends on a library version or environment, display the output from the actual execution used for the lesson.
- Keep code and output readable. Do not use decorative fake terminal results.

### 4. Text and language rules

- All on-screen technical terms must be spelled correctly.
- Preserve the exact technical terminology used in the voice script.
- English technical terms should remain in English.
- Do not add explanations, definitions or examples that are absent from the voice script.
- Do not add subtitles that change the meaning of the narration.
